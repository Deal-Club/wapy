# Wapy — Série de vidéos TikTok / Reels / Shorts

Plan éditorial des vidéos de promotion de Wapy sur les réseaux, et prompts de
production prêts à remettre à Claude Code (HyperFrames, whiteboard).

- **Format** : 9:16 (1080×1920), 15–45 s, sous-titres incrustés obligatoires.
- **Cible** : commerçants et gérants d'Afrique de l'Ouest (restaurant, salon,
  boutique, pharmacie, hôtel…) qui reçoivent leurs clients sur WhatsApp.
- **Règle d'or** : chaque vidéo défend UN message, pas un thème. Tout ce qui est
  montré existe dans le produit — rien d'inventé.
- **Démarrage** : vidéos whiteboard (réalisation HyperFrames, voir le prompt § 4),
  puis screen-recordings réels pour les démos.

pharmacie) en changeant le décor — mêmes scripts, quatre fois plus de contenu,
aligné sur les pages `/secteurs` du site.

**Cadence recommandée** : 3 vidéos/semaine — 1 accroche (phase 1), 1
démo/fonction (phases 2-4), 1 conversion (phase 5).

## 2. Personnages récurrents Wapy (toutes vidéos)

Comme le technicien AGM TEC, Wapy a ses personnages fixes, reconnaissables
d'une vidéo à l'autre :

- **Mariam** — la gérante. Femme ouest-africaine, ~35 ans, foulard noué et
  tablier, expressive (fatigue, surprise, sourire de soulagement). C'est ELLE
  l'héroïne : le spectateur est Mariam.
- **Le client** — figurant variable selon le sketch (jeune homme pressé, couple,
  cliente fidèle). Il agit : il écrit, il attend, il part ou il commande.
- **Le téléphone** — quasi-personnage : gros plans sur l'écran, bulles WhatsApp
  vertes qui se dessinent, notifications qui vibrent (lignes de mouvement).
